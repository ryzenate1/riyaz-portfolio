## About

RYZEN STUDIO is a modern portfolio website showcasing creative web development and design projects. Built with cutting-edge technologies and featuring interactive elements, mini-games, and stunning animations.

## Features

- ⚡ **Next.js 16** with App Router
- 🎨 **Tailwind CSS 4** for styling
- 🎬 **Framer Motion** animations
- 🎮 **Interactive Mini-Games**
- 📱 **Fully Responsive** design
- 🖥️ **Terminal Bootloader** experience
- 🎯 **Custom Cursor** effects
- 📧 **Contact Form** with Resend integration

## Interactive Features

- **Fun Zone** - Interactive gender selection game
- **Ambition Section** - Choose your path with terminal hacker mode
- **Memory Game** - Test your memory with card matching
- **Snake Game** - Classic snake game
- **Typing Speed Test** - Test your typing skills

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Animation:** Framer Motion
- **CMS:** Sanity
- **Email:** Resend
- **Deployment:** Vercel
